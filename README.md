## Running a solution

Each file uses LeetCode's `Solution` class format, so it can be pasted straight into the matching problem on [leetcode.com](https://leetcode.com/problemset/). Some files also include a sample call at the bottom and can be run locally:

```bash
python Palindrome_Number.py
```
